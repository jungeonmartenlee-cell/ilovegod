# 하나님을사랑합니다

한국교회 청년부서를 위한 홈페이지 틀입니다. QR코드로 휴대폰에서 접속해서 부서 소개와 매주 설교 본문에 따른 큐티 나눔 자료를 보는 사이트예요.
**부서가 바뀌어도 설정 파일 하나(`src/config.ts`)만 고치면 그대로 쓸 수 있어요.**

## 페이지 구성

| 주소 | 내용 |
|---|---|
| `/` | 홈 — 이번 주 큐티 카드, 부서 소개 한 줄, 예배 시간·장소 |
| `/about` | 부서 소개 — 비전, 섬기는 사람들, 모임 안내 |
| `/qt` | 지난 큐티 목록 (최신순) |
| `/qt/2026-11-01` | 주차별 큐티 페이지 (파일 이름 = 주소) |
| `/qt/latest` | **QR코드용 고정 주소** — 항상 최신 큐티로 이동 |

## 자주 하는 일

### ✍️ 매주 큐티 올리기
1. `src/content/qt/_템플릿.md`를 복사해서 이름을 날짜로 바꿉니다. 예: `2026-11-08.md`
2. 맨 위 `---` 사이 항목(날짜, 제목, 본문 구절, 설교자, 한 줄 요약)을 채웁니다.
3. 본문(성경 본문, 핵심 메시지, 묵상 질문, 나눔 질문, 적용과 기도)을 채웁니다.
4. GitHub에 저장(commit)하면 1~2분 뒤 사이트에 자동 반영돼요. 홈 카드, 목록, `/qt/latest`가 모두 알아서 바뀝니다.

> 미리 써 두고 숨기고 싶다면 frontmatter에 `draft: true`를 넣으세요.

### 🏠 부서 정보 바꾸기 (예배 시간, 소개 문구, 섬기는 사람들, 설문지 버튼)
모두 `src/config.ts` 한 파일에 있어요. 따옴표 `'...'` 안의 글자만 바꾸면 홈과 소개 페이지에 같이 반영돼요.

## 🌱 새 부서(교회)에서 쓰기
1. GitHub에서 이 저장소를 복사합니다. 저장소 화면의 **Use this template** 또는 **Fork** 버튼을 누르면 돼요.
2. `src/config.ts`를 새 부서 정보로 고칩니다.
3. `src/content/qt/` 안의 예전 큐티 파일을 지웁니다. (`_템플릿.md`는 남겨 두세요.)
4. `astro.config.mjs`의 `site:` 주소를 새 사이트 주소로 바꿉니다.
5. Vercel에서 새 저장소를 연결하면 새 사이트가 생깁니다.

## 성경 본문 저작권 안내
개역개정 성경은 대한성서공회에 저작권이 있어요. 매주 몇 구절 정도 인용하는 것은 일반적으로 문제가 되지 않지만, 장 전체를 계속 싣는 것은 피하는 게 좋아요.

## 개발자용 명령어
```bash
npm install      # 처음 한 번
npm run dev      # 내 컴퓨터에서 미리보기 (http://localhost:4321)
npm run build    # 배포용 파일 만들기 (dist 폴더)
```
